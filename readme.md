# 🔬 LOGMAC System

**Latency-stage Oncological Genomic Molecular Analysis & Classification**

🏆 iVIX 2026 International Virtual Innovation Competition Entry

## 📋 Overview

LOGMAC is an AI-powered early cancer detection system that identifies pre-malignant transitions by analyzing molecular velocity (Omic Gradients) rather than static mutations. The system combines Graph Neural Networks with LSTM networks to predict cancer progression 12-14 months earlier than conventional methods.
